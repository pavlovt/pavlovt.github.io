BraceML

HTML templates without the boilerplate. BraceML is a brace-based template language: { } wraps an element's children, the way SCSS wraps CSS rules. It compiles to plain HTML, Svelte 5 and React at build time, so browsers and frameworks never see it.

Convert HTML to BraceML Source on GitHub Language guide

No closing tags

In HTML every element is written twice. In BraceML, selectors do the naming and braces do the nesting.

HTML

<nav class="menu">
  <ul>
    <li><a href="/">Home</a></li>
    <li><a href="/shop">Shop</a></li>
    <li><a href="/about">About</a></li>
  </ul>
</nav>

BraceML

nav.menu > ul {
  li > a href=/ 'Home'
  li > a href=/shop 'Shop'
  li > a href=/about 'About'
}

One template for Svelte and React

The same control flow compiles to Svelte blocks or to JSX. The React target adds className, key and the rest for you.

if users.length == 0 {
  p.muted 'No users yet'
} else {
  ul {
    each users as user (user.id) {
      li > a href="/users/{user.id}" '{user.name}'
    }
  }
}

Features

  • Selectors: tag#id.class, with div as the default tag.
  • Blocks: if, else if, else, each, await, key and snippet.
  • Components: a tag that starts with an upper-case letter, such as Card title="Hi".
  • Mistakes are errors: unknown lower-case tags and unclosed braces are reported with a line and column, instead of being guessed at like broken HTML.
  • Editor support: a VS Code extension and a language server with highlighting, completion, live errors and formatting.
  • Tooling: a formatter, a Prettier plugin, source maps, and an HTML converter.

Get started

SvelteKit

npm i -D @braceml/svelte

// svelte.config.js
import { vitePreprocess } from '@sveltejs/vite-plugin-svelte';
import { braceml } from '@braceml/svelte';

export default {
  preprocess: [braceml(), vitePreprocess()],
};

React

npm i @braceml/react

// vite.config.js
import react from '@vitejs/plugin-react';
import { braceml } from '@braceml/react/vite';

export default {
  plugins: [braceml(), react()],
};

Command line

npx @braceml/cli page.braceml                  # HTML to stdout
npx @braceml/cli page.braceml -t svelte -o page.svelte
npx @braceml/cli convert page.html -o page.braceml

To see it in a real app, look at brace-store, a SvelteKit storefront built twice, once in BraceML and once in HTML, so you can compare them side by side. BraceML grew out of easy-html, and easy-html templates are valid BraceML.

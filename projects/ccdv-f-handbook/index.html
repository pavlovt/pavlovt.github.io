CCDV-F Study Handbook

A three-volume study handbook for the Claude Certified Developer – Foundations (CCDV-F) exam, in EPUB. It has 1,007 practice questions, each with an answer and an explanation.

Download the EPUBs Source on GitHub

The three volumes

BookContentsDownload
A Study Handbook for the CCDV-F Exam 12 chapters across the eight exam domains, chapter questions, a 53-question mock exam, answer keys, a glossary and resources EPUB
Volume II: Depth in the Heavy Domains 5 advanced chapters, a 60-question advanced mock exam and answer keys EPUB
Volume III: Twelve Advanced Mock Exams 12 full-length exams of 53 questions each, answer keys and a guide to reading your results EPUB

How it is checked

A script, preflight.py, checks every question against its answer key. It finds questions with no key entry, duplicate IDs, answers that aren't among the options, answer counts that don't match “Select TWO” or “Select THREE”, and explanations that contradict the key. The v1.0.0 release has 0 defects and 0 warnings.

Build it yourself

The books are written in Markdown and built into EPUB with pandoc and Python 3:

git clone https://github.com/pavlovt/ccdv-f-handbook
cd ccdv-f-handbook
python build.py --check

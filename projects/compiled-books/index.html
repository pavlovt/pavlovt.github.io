Compiled Books

Technical books compiled with Claude, written in Markdown and built into EPUB. They cover Svelte 5, SvelteKit 3 and Astro 7 in depth, and there is a nine-day SvelteKit interview-prep course.

Download the EPUBs Interview-prep quizzes Source on GitHub

The books

Svelte 5 in DepthHow Svelte 5 really works, from the compiler that turns a .svelte file into JavaScript to the signals, batches and flush loop behind $state, $derived and $effect. Twenty chapters then cover templates, components and snippets, bindings, styling and motion, shared state, async Svelte, SSR and hydration, TypeScript, testing, accessibility, performance and custom elements, and end with migrating from Svelte 4. Download EPUB
SvelteKit 3 in DepthSvelteKit 3 from the request lifecycle outwards: routing, data loading, invalidation and streaming, form actions and progressive enhancement, and remote functions with query, form, command and single-flight mutations. Later chapters cover hooks, errors, rendering modes, state, environment variables, authentication, security hardening, caching, observability, adapters and deployment, and close with a migration from SvelteKit 2 and a capstone architecture. Download EPUB
Astro 7 in DepthAstro 7 with Svelte 5 islands: the rendering model, the .astro language, state and events across islands, and advanced routing. It goes on to content collections and loaders, Markdown and MDX, on-demand rendering, server islands, middleware, actions, sessions and route caching, images and fonts, view transitions, internationalization, security, testing and integrations, and ends with a multilingual shop built as a capstone. Download EPUB
SvelteKit Interview PrepA nine-day course for SvelteKit interviews, two hours a day. Seven daily lessons build from Svelte 5 runes and components through SvelteKit routing, data, hooks and rendering modes, to testing with Vitest and Playwright and production topics like auth, security and deployment. Each day ends with a quiz, followed by two mock interviews, a live-coding playbook, a question bank, three example projects to build with Claude Code and three final tests. Download EPUB
Living Well with Type 2 DiabetesA practical guide to living with type 2 diabetes, written for everyday use. It explains what the condition is and which numbers to know, then covers weight loss and remission, eating well and eating in real life, exercise, sleep and stress, medicines, monitoring and emergencies, and protecting the heart, kidneys, eyes and feet. It ends with a 12-week action plan, a quick reference and a glossary. Educational only, not medical advice. Download EPUB

Each of the three in Depth books has 20 chapters, a preface, answers to the chapter review questions, six final tests and their answer key.

SvelteKit Interview Prep

A study course built on the Svelte 5 and SvelteKit 3 books. It has seven daily lessons with quizzes, two mock interviews, a live-coding playbook with tested drills, three example projects to build with Claude Code, and three final tests.

Every quiz and final test is on one interactive quiz page, where you can pick a quiz, answer it and check your answers.

Build it yourself

Every book is built the same way, with pandoc and Python 3:

git clone https://github.com/pavlovt/compiled-books
cd compiled-books
python build.py --list                # list the books
python build.py                       # build every book into dist/
python build.py svelte-5-in-depth     # or just one

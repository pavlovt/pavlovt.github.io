Kvesto

Open source surveys, anywhere. Kvesto is a survey library: you define a survey as JSON and render it with a lightweight JavaScript core, in plain HTML or in React, Vue or Svelte. Build surveys visually in the editor and explore the responses in the dashboard. Everything is MIT, including the editor and the dashboard.

Source on GitHub Package on npm

A survey is JSON

One versioned format describes the questions, pages, conditions and validation. The core, the server and the OpenAPI spec all share its schema.

{
  "schemaVersion": 1,
  "id": "customer-feedback",
  "title": "Customer feedback",
  "pages": [{
    "id": "p1",
    "elements": [
      { "id": "email", "type": "text", "inputType": "email", "title": "Your email", "required": true },
      { "id": "nps", "type": "rating", "title": "How likely are you to recommend us?", "min": 0, "max": 10 }
    ]
  }]
}

Storage is a setting

The core never talks to a server on its own. Keep responses in the browser, plug in your own backend, or use the included server: a Hono REST API on SQLite with documented OpenAPI endpoints.

Features

  • Question types: text, choice, dropdown, rating, matrix, grid, ranking, file upload, slider, tags, image choice, signature and calculated values.
  • Logic: conditional questions and panels, repeating panels, and validation.
  • Anywhere: a <script> bundle, a <kvesto-survey> element, and React and Vue components.
  • Editor and dashboard: embeddable Svelte 5 components, with Excel export of responses.
  • Hosted surveys: the server serves each survey as a page and an embed script, with a strict Content Security Policy.

Get started

npm install kvesto

import { mountSurvey } from "kvesto";

mountSurvey(document.getElementById("survey"), {
  survey,
  onComplete: ({ response }) => console.log(response.answers),
});

See the README for the server, the editor, the dashboard and every question type.
